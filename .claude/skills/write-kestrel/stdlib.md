# The standard library

Source: `lang/std/<module>/`. Exact signatures: `docs/stdlib/std.<module>.md`
(generated by the `stdlib-docs` skill). Every public std item is
auto-imported in user code.

**Check before you call.** Std APIs get renamed between releases. Before using
a method you haven't seen this session, grep for it:
`rg 'func readText' lang/std` or open the module's `docs/stdlib` page.

## Where things live

| Module | What's in it |
|---|---|
| `std.core` | `Bool`, ranges (`Range`, `ClosedRange`, …), operator and literal protocols, `Equatable`, `Comparable`, `Hashable`, `Cloneable`, `Defaultable`, `Indirection`, `DecaysFrom` |
| `std.numeric` | `Int8`…`UInt64`, `Float32`/`Float64`, `Numeric`/`Integer`/`FloatingPoint`, random (`DefaultRandom`, `SystemRandom`, `ChaCha8`) |
| `std.text` | `String`, `StringSlice`, `Char`, `StringBuilder`, views (`bytes`, `chars`, `graphemes`, `lines`, `words`), formatting (`Formattable`, `Formatter`) |
| `std.collections` | `Array`, `Slice`, `Dictionary`, `Set`, `Deque`, `Heap`, hashers, `SeqRange` / `SliceIndex` |
| `std.iter` | `Iterator`, `Iterable` and the adapters (`map`, `filter`, `zip`, `enumerate`, `chain`, …) |
| `std.result` | `Optional`, `Result` |
| `std.memory` | `Pointer`, `RawPointer`, `Allocator`, `SystemAllocator`, `ArenaAllocator`, boxes (`RcBox`, `CowBox`, `OwnedBox`), `Layout`, `UnsafeSlice` |
| `std.streams` | `print` / `println` / `eprintln` / `readLine`, `Readable` / `Writable`, buffered readers and writers, `IoError` |
| `std.files` | `Path`, `File`, `Directory`, `Metadata`, `OpenOptions` |
| `std.system` | `Process` (arguments, exit), `Environment`, `Command` (run programs), `ExitCode`, `Machine` / `Platform` |
| `std.time` | `Duration`, `Stopwatch`, `sleep(for:)` |
| `std.network` | `TcpListener`, `TcpStream`, `UdpSocket`, `UnixStream`, `IpAddress`, `SocketAddress` |
| `std.ffi` | `CString`, `FFISafe` |

Packages beyond std (`lang/regex`, `lang/datetime`, `lang/crypto`,
`lang/perch` for HTTP, `lang/quill-json`, …) are built with `flock`; each has
a `README.md`.

## Common call shapes

```kestrel
module StdTour

@main
func main() -> Int64 {
    // Files: single-name params are positional. A string literal is a Path.
    match File.writeText("/tmp/out.txt", "hello\n") { .Ok(_) => (), .Err(e) => { eprintln("write: \(e)"); return 1; } };
    guard let .Ok(text) = File.readText("/tmp/out.txt") else { return 1; }
    print(text);

    // Process and environment
    let args = Process.arguments();                 // Array[String], args(0) is the program
    let home = Environment.variable("HOME") ?? "";

    // Running programs
    match Command("echo").argument("hi").output() {
        .Ok(o) => print(o.standardOutputText() ?? ""),
        .Err(e) => eprintln("\(e)")
    };

    // Text
    let fields = "a,b,,c".split(by: ",");           // lazy view of &StringSlice
    let joined = ["x", "y"].joined(by: "-");
    let n = Int64(parsing: "42") ?? 0;              // parse returns Optional
    let shout = home.trimmed().uppercased();
    var sb = StringBuilder();
    sb.append("built");
    let built = sb.build();

    // Collections
    var counts: [String: Int64] = [:];
    counts("a") = 1;                                // insert or overwrite
    let a = counts("a") ?? 0;                       // lookup is Optional
    for (key, value) in counts { println("\(key)=\(value)"); }
    let _ = counts.remove("a");
    var seen: Set[Int64] = [];
    seen.insert(3);

    // Time
    let watch = Stopwatch.start();
    sleep(for: Duration.milliseconds(1));
    let _ = watch.elapsed;

    println("\(args.count) \(joined) \(n) \(a) \(built) \(shout.isEmpty)");
    0
}
```

## Patterns worth knowing

- String length: `s.bytes.count` (O(1)) or `s.chars.count` (O(n)); no `s.count`.
- `Array`, `String`, `Dictionary` and `Set` take an allocator type parameter
  that defaults to `GlobalAllocator` (= `SystemAllocator`). You only name it
  to use another allocator such as `ArenaAllocator`.
- An `Optional` interpolated whole prints as `Some(…)`; unwrap it first.
- `readLine()` returns `Result[Optional[String], IoError]`: an error, a line,
  or end of input.
- `exit(code)` ends the process immediately. Prefer returning an exit code
  from `@main`.
