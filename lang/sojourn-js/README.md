# sojourn-js

The JavaScript front end for Sojourn, the browser: a lexer, an ESTree-shaped
AST and a recursive-descent parser for ECMAScript 2024 scripts and modules.

## Usage

```
./build.sh                                  # builds build/sojourn-js
./build/sojourn-js parse [--module] FILE    # print FILE's syntax tree
./build/sojourn-js test262 DIR [--verbose]  # run tc39/test262-parser-tests
```

`DIR` is a checkout of https://github.com/tc39/test262-parser-tests. Files
with `.module.` in the name are parsed as modules.

## Files

| File | What |
| --- | --- |
| `src/token.ks`, `src/lexer.ks` | Tokens and the lexer. Regexes and template continuations are rescanned on the parser's request. |
| `src/unicode.ks`, `src/data/*.bin` | ID_Start / ID_Continue ranges, generated by `tools/generate_unicode.py`. |
| `src/ast.ks` | The syntax tree. |
| `src/parser*.ks` | The parser: statements, expressions, patterns (the cover grammar) and declaration scopes for redeclaration errors. |
| `src/dump.ks` | An S-expression dump, used to compare `pass/` and `pass-explicit/` trees. |
| `src/main.ks` | The command line and the test262 harness. |

## test262-parser-tests

| Folder | Result |
| --- | --- |
| pass | 1983/1983 parse |
| pass-explicit | 1947/1983 same tree as pass/ |
| fail | 718/729 rejected |
| early | 663/668 rejected |

What's left:

- **Suite errata** (the suite predates later spec changes):
  - `pass-explicit`: the 36 differences are twins that don't match their
    `pass/` file (renamed identifiers, renumbered literals, a parenthesized
    string read as a directive, `a((1,2,3))` vs `a(1,2,3)`).
  - `fail`: `'\8'` and `'\9'` (allowed in sloppy code since ES2021), class
    fields `(class {a})` and `(class {a=0})` (ES2022), and
    `for (var x = 1 in …)` (Annex B).
  - `early`: `{ function a(){} function a(){} }` in sloppy code, which Annex
    B allows.
- **Not done yet: regular expression validation under `/u`.** Regex bodies
  are scanned but not parsed, so `/\1/u`, `/{*/u`, `/}?/u`,
  `/(?!.){0,}?/u` and `/\u{110000}/u` are accepted.
